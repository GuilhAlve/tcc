<h1>💻 Nexadesk</h1> 
<h3>Sistema de HelpDesk feito para ajudar as pessoas a resolver seus problemas relacionados à tecnologia. </h3>

<h1>📌 Sobre o projeto</h1>
<h3>A NexaDesk é uma plataforma de suporte técnico que permite os usuários registrar problemas por meio de chamados. Os administradores podem visualizar, atender e finalizar chamados após a resolução do problema.</h3>

<h1>🎯 Objetivos</h1>
<p><b>- Facilitar a  abertura de chamados.</b></p>
<p><b>- Registrar problemas e suas respectivas soluções.</b></p>
<p><b>- Melhorar a comunicação entre usuários e admin.</b></p>
<p><b>- Acompanhar o andamento de chamados.</b></p>

<h1>⚙️ Funcionalidades</h1>
<p><b>- Cadastro de usuários;</b></p>
<p><b>- Login;</b></p>
<p><b>- Abertura de chamados;</b></p>
<p><b>- Atendimento dos chamados;</b></p>
<p><b>- Encerramento de chamados;</b></p>
<p><b>- Sistema de notificações</b></p>
<p><b>- Dashboard de estatísticas</b></p>

<h1>🛠️ Tecnologias utilizadas</h1>
<p><b>- HTML</b></p>
<p><b>- CSS</b></p>
<p><b>- JavaScript</b></p>
<p><b>- Python/Node.js</b></p>
<p><b>- Git e Github</b></p>
<p><b>- NoSQL</b></p>

<h1>🎮 Como executar o sistema</h1>
<p><b>1. Entre em seu terminal e coloque "git clone https://github.com/GuilhAlve/tcc.git" (sem as aspas)</b></p>
<p>Assim:</p><img src="./img/gitclone.png">

<p><b>2. Depois entre na pasta colocando "cd tcc" e depois "code ." no terminal:</b></p>
<img src="./img/tcc.png">

<p><b>3. No terminal do vscode, coloque "npm start" (É necessário ter o npm instalado)</b></p>


<h1>🚀 Exemplo simples do que o sistema faz</h1>
<p><b>Usuário</b></p>↓
<p><b>Cria uma conta ou faz login</b></p>↓
<p><b>Abre um chamado</b></p>↓
<p><b>Administrador recebe o chamado</b></p>↓
<p><b>Administrador resolve o problema</b></p>↓
<p><b>Chamado é encerrado</b></p>
